The first release of MultiTasker: an always-on-top widget that keeps the tasks you have in progress in front of you,
for people who juggle several at once.

Install with the `-setup.exe` below. It installs for you only, needs no admin rights, starts with Windows, and updates
itself once a newer version is published.

## Your tasks, wherever they live

- Keep tasks on this computer, or take them from **JavaDashboard**, **Todoist** or a **Notion** database.
- Tasks kept on this computer sync between your computers through a shared folder, **OneDrive**, **Google Drive** or
  S3-compatible storage. Online lists sync themselves.
- Your settings and the day's plan follow you between computers through the same place.

## Working on several things at once

- The widget shows what's in progress, with time spent, the next checklist step and due times. Drag a task up from
  the to-do list to start it, and right-click any task for everything else.
- **Pick up where you left off.** Pausing asks for a note on where you stopped; starting again shows it and offers to
  open the task's files and pages, switching to browser tabs that are already open.
- **Waiting on something?** Choose a window (a build, a render, an installer) or a file being saved, and MultiTasker
  tells you when it's done and takes you back to the task.
- **AI replies.** Turn on reply notices in the browser extension, and when Claude, ChatGPT, Gemini or another AI chat
  finishes a reply while you're elsewhere, MultiTasker says so and takes you back to the tab.
- **It notices what you're working on.** Linked files, apps and pages mark their task as active, and tasks start on
  their own after a short wait (adjustable, or off). It pauses tasks while you're away and asks whether you're still on
  one when none of its things have been open for a while.
- **Quick switcher** (`Ctrl+Alt+Space` by default) to switch to, start or add a task from anywhere.

## Planning and finishing

- A **Today** view and a morning prompt to pick what the day is for.
- Checklists, due times with reminders, and nudges for tasks due soon that haven't been started.
- **Time** view of where your time went today and this week.
- **Hand in** finished work: keeps a copy of each version, and checks files are closed, not empty, and named as
  expected, and that links can be opened by others.
- Run a task's dev servers and project commands from the task.

## Browser extension

The extension for Chrome, Edge and Brave links tabs to tasks, tells MultiTasker which page you're on, and opens a
task's pages together. Its popup shows whether it can reach MultiTasker. If something on your computer gets in the
way, such as Windhawk, MultiTasker names it and says how to fix it.

The extension zip below is for the Chrome Web Store and Edge Add-ons. Until it's published there, load the `extension`
folder from the repository as an unpacked extension (see `docs/browser-extension.md`).

## Known limits

- Windows only.
- This is a first release: it has mostly been used on one computer so far. Please report anything that misbehaves.
